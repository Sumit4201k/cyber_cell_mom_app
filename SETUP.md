## 🐳 Option 1: Docker Deployment (Recommended for Quick Start)

The entire platform is containerized into 3 microservices (Python AI, Node.js API, React Frontend):

```bash
# 1. Clone or navigate to the project directory
cd cyber_cell_mom_app

# 2. Build and launch all containers
docker compose up --build
```
*Or using npm:*
```bash
npm run docker:up
```

### 🌐 Containerized Endpoints:
- **Frontend Dashboard:** [http://localhost:5173](http://localhost:5173)
- **Node.js Express Backend:** [http://localhost:5000](http://localhost:5000)
- **Python FastAPI Speech Engine:** [http://localhost:8000](http://localhost:8000)

To stop the containers:
```bash
docker compose down
# or: npm run docker:down
```

## 🪟 Option 2: Windows Setup (Native)

### Method A: One-Click Automated Installer (Fastest)
1. Double-click **`setup.bat`** in the root directory.
2. The script will:
   - Detect or install Python 3.11 runtime.
   - Install all Python AI dependencies (`faster-whisper`, `presidio`, `spacy`, `en_core_web_sm`).
   - Install all Node.js dependencies for backend and frontend.
   - Run cryptographic ledger verification tests.
   - Audit ports `5000`, `8000`, and `5173`.
3. To start the application at any time, double-click **`run.bat`** or run:
   ```cmd
   npm run start:full
   ```

### Method B: Manual Windows PowerShell Setup
```powershell
# 1. Install root & Node dependencies
npm install
cd backend && npm install && cd ..
cd frontend && npm install && cd ..

# 2. Install Python AI Microservice dependencies
cd python-service
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m spacy download en_core_web_sm
cd ..

# 3. Verify cryptographic ledger & RBAC rules
node backend/test_qa_suite.js

# 4. Launch all 3 services concurrently
npm run start:full
```

## 🛠️ Common Troubleshooting

### 1. `Port 5000 / 8000 / 5173 already in use`
- On Windows: Run `run.bat` (it automatically terminates orphan background listeners) or in PowerShell:
  ```powershell
  Get-NetTCPConnection -LocalPort 5000, 8000, 5173 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
  ```
- On Linux/macOS:
  ```bash
  kill -9 $(lsof -t -i:5000 -i:8000 -i:5173) 2>/dev/null
  ```

### 2. `FFmpeg not found` (Linux/macOS)
- Ubuntu/Debian: `sudo apt update && sudo apt install -y ffmpeg`
- macOS: `brew install ffmpeg`

### 3. `Spacy en_core_web_sm missing`
- Run: `python -m spacy download en_core_web_sm`
